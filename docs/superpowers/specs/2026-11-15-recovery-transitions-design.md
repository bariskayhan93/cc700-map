# Bounded transition-aware recovery study

Owner priority: finish useful recovery research, without another stationary bug
loop. This is the next PC-only milestone under standing implementation authority.

Choose local barrier cuts and incoming-edge turn states over whole-way deletion.
Removing all filters would invent access; implementing a complete routing engine
would exceed this deliverable. Preserve the previous study as a comparison.

Compile intact snapshots only. Keep primary ways; outside reference-only ways
never become routable. Ordinary way access/direction policy remains unchanged.
Block incident edges at denied/unknown barrier nodes, rather than the whole way.
Explicit bicycle admission can allow selected conventional barrier types, but
physical width/condition remains unvalidated. Node access without a barrier also
applies. Unknown/conditional node access stays blocked.

Support single from-way / via-node / to-way restrictions with documented no/only
values. Same-way U-turns distinguish immediate reversal from continuation.
Unsupported relations retain conservative member-way/node quarantine. Explicit
bicycle restrictions override general exceptions; conditional/time-dependent
forms remain unavailable. Search must retain incoming directed edge identity:
settling only by node can lose legal alternatives. A restricted origin without
an incoming edge remains unavailable. Keep bounded work/queue/path/distance and
never emit partial routes. Preserve deterministic outputs and source immutability.

Replay the same 30 recorded scenarios, report policy differences and unchanged
association/online-selection gaps. Measure actual candidate JSON and a proposed
binary leg encoding separately from graph JSON; do not infer device RAM/timing.
If no useful cases emerge, record that and stop rather than relaxing defaults.
No firmware, production generator, map budget or deployed UI changes. Normal
result is a labelled candidate; insufficient source/state/resources is unavailable;
ordinary device navigation is untouched, so restoration needs no device action.
