# Complete PC recovery feasibility pass

Standing owner authority covers inline implementation of the four remaining PC
study steps in one turn. Success is a reproducible, tested feasibility decision,
not a legal cycling or device release claim. No firmware, production generator,
map budgets or deployment changes. Preserve source/route bytes and private data.

## Approach and constraints

Prefer generation-time candidate computation and bounded device lookup; measure
an actual compact graph as the alternative. Display-only context has no routing
ability. Avoid infinite incident fixes: one implementation/review/fix pass, then
report evidence and any remaining deployment gates.

1. Associate against original source segments BEFORE access filtering. Index
   original segments spatially, project fixes onto them within 25 m, compare
   competing segments within 5 m of the best, and use past movement heading only
   when reliable (>=5 m displacement within 10 s). Disconnected parallel roads,
   crossings, near endpoints (<2 m), wrong levels and unknown heading must retain
   ambiguity. Never snap a denied source onto an admitted neighbour. A selected
   projection is a candidate association, not surveyed physical connectivity.
2. Preserve conservative access as comparator. A named NRW firm-path study
   profile may infer access only on path/track with an explicit firm surface,
   absent bicycle/vehicle/access denial and absent designated foot/horse-only
   meaning. Explicit denials, conditional/directional access and motorroad remain
   excluded. Inference is based on documented OSM defaults and NRW fixed-way rule,
   not proof of mapped ownership, signs, forest/protected-area context or closures.
3. Read native route points with bounds and ordered native distance. Generate
   route visit anchors every 100 m and associate using route bearing (directed,
   not interchangeable at start/finish/repeated passes). Restrict targets to
   progress >last trusted entry+25 m and <=entry+3 km; never use later ride fixes
   to select targets. Keep historical anchor/recording gaps labelled. Unknown
   progress is unavailable; no proximity-based finish inference.
4. Split only the SAME original source segment at selected projections. Preserve
   direction, barriers and way identity; no cross-road connector. Require target
   arrival to match the direction of route continuation. Virtual splits must not
   manufacture a U-turn. Original restriction-node uncertainty remains blocked.
5. Replay same saved off-route samples with both profiles and compare old
   nearest-node results. Report recording gaps, geometric ambiguity and access
   inference separately; zero validated cycling paths remains explicit.
6. Sample actual eligible original network nodes in disjoint 0–1/1–2/2–3 km bands
   from the WHOLE route, with deterministic low/mid/high local road-density
   strata, bounded samples and source-boundary exclusions. Density is measured,
   not a claim of city/village/forest land cover. Add synthetic known environment
   controls. Spatial targets use nearest ordered route visit as an explicitly
   hypothetical last-progress anchor, never live evidence.
7. Serialize candidate legs and compact CSR graph arrays; round-trip graph search
   tests. Measure full-snapshot and radius-local subgraphs, path work and missing
   associations. Packet bytes include declared fields only. Account lookup/visit
   metadata separately; decoded/transition RAM, firmware stack/timing, source
   completeness, physical/legality validation and arbitrary-area coverage remain
   unmeasured. Do not select a target format on one tiny leg.

Normal: bounded labelled candidate. Admission: supported source/access/association,
ordered progress, supported restrictions and independent work/packet limits.
Fallback: explicit unavailable, basemap stays; future runtime must suppress stale
stock recovery cues. Restoration: ordinary guidance only after stable verified
route rejoin; no device state changes in this PC study.
