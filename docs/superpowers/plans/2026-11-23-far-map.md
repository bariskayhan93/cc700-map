# Far Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page-built far map (classed ways, green and water) drawn by position under the detail map, plus exit edges for the violet line.

**Architecture:** The page builds route-file section type 4 "CCFM" from the routing Overpass answer (ways and areas); the unit reads it in `cc_iter` before the detail map and draws areas and classed lines with the raster module. Exit edges are a page-only change of the way-back tree.

**Tech Stack:** ES modules (node tests in `tools/`), C for the unit (area 2, `tools/cc27_build.py`), host C builds (`tools/*_host.c`).

**Spec:** `docs/superpowers/specs/2026-11-23-far-map-design.md`

## Global Constraints

- File guard 4,000,000 B (`js/cc27_file.js` FILE_LIMIT); default reach line3k; budget test route C2 (70 km) at 3 km.
- Cells 256 m (shift 12), points on the 0.5 m grid (shift 3), <= 32 points per line, cell body <= 2,048 B.
- Line caps 60,000 work and 2,048 points per screen (GREY_CAPS); fill cap 61,440 px per screen; far time stop 60 ms (FAR_US).
- Classes: 0 main, 1 minor, 2 cycle, 3 track, 4 path, 5 water line; 8 water area, 9 forest, 10 green.
- Detail reach per class (`js/mapsec.js:311`): main 1,000, minor 550, cycle 350, track 300, path 300, water line 600 m.
- Areas >= 5,000 m², simplified 12 m, clipped to each cell, ring 3..64 points.
- Area-2 code <= 18,404 B; max function frame 512 B; 0 B extra heap (use the existing PSRAM GL buffer).
- Exit edges: only ways whose single failure is "highway-needs-explicit-bicycle-access" with highway track, path or bridleway.
- Write in ASD-STE100 in docs and commit messages. Commit only when the owner asks.

## Review Focus

1. A way that leaves and enters the detail reach several times: each far piece starts and ends at the reach point (test in Task 1).
2. An area larger than one cell and a concave area: clipping keeps only the part inside each cell, no self-crossing ring (Task 1).
3. A damaged type 4 section (cut body, count past the end): the unit draws no far map for that frame and the detail map draws (Task 5).
4. A file with grey type 2 and no type 4 (old page): today's behaviour unchanged (Task 5).
5. A rider on a street next to a track: the violet line never enters the track (Task 3).
