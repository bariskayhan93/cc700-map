# Historical Tour D3 artwork

These illustrations were made for the earlier preview UI on 13 November 2026.
They predate the current two-row card, full-display geometry, serialized outgoing
caption handling and Sunlight v21 profile. They are **historical reconstructions,
not exact current device captures**. The OnelapFit-style panels are reconstructed
schematics, not output from OnelapFit.

Their route source is Düsseldorf's public
[Tour D3](https://www.duesseldorf.de/radverkehr/fahrradtouren/tour-d).
The old artwork is retained for comparison of map ideas and documentation history.
Use the current synthetic UI examples in the [README](../../README.md) for current
page layout; differences in route and position prevent direct map-content comparison.
