# cc27: one release for a stable map, grey streets, reach 1 to 3 km and elevation (19 Nov 2026)

Status: host only. The image is built in `.local/cc27/` (private). It is not on the unit. The cc27 tree is not
committed: the build mark is the old HEAD `f8914d0` and the receipt says `source_dirty: true`. Build the image again
after the owner commits the tree. Design: `docs/current/one-release-design-2026-11-19.md`. Plan:
`docs/current/one-release-plan-2026-11-19.md`.

## What changed

- **Addresses:** all stock addresses are in `firmware/common/fw.h`. Shared types are in `firmware/common/types.h`.
- **Own line drawer:** `firmware/raster` draws map lines, grey streets and (with `F_OWN`) the way-back line into the
  RGB565 canvas. No anti-aliasing. The stock route line, the turn arrows and the route dots stay with LVGL.
- **Frame stops:** the 400 ms stop is checked only before the fills, before each level 0 to 4, before the signals and
  before the names. A road never shows its edge without its core.
- **Block switches:** the last entry of each map block holds the flags (`F_OWN` 1, `F_TEXT` 2, `F_ROUTE` 4). A block
  without it draws as cc26. `mapdec` and the C4 base do not change.
- **Section table:** the route file ends with `CCWS` (last 64 B): way-back (type 1), grey (type 2), elevation (type 3).
- **Way-back version 3:** 2 m distance steps, up to 8,190 m. The page offers 1, 2 or 3 km and steps down when the data
  does not fit.
- **Grey streets:** layer version 2 with a directory and the caps in the header. The page proves the work of each
  screen (64 m grid, 16 headings) and removes the shortest dead ends until every screen is inside the caps. The unit
  gets a view from 4 anchors and draws every line of the screen cells, with no stock projection call for a grey line.
- **Elevation strip:** on the route, the next 1 km of the profile at (4, 68), 232 x 32 px. The progress `T - U` is used
  only through the gates of design deviation 8.
- **Names and landmarks:** a street name stands 20 m or more from the route and from each junction. Drinking water,
  churches and supermarkets are names of their own (priority after the route streets).

Not measured (gaps):

- **Way-back and grey at 1, 2 and 3 km.** No saved street snapshot covers the two routes (the 3 km snapshot of the
  earlier study is gone). A new snapshot needs an Overpass request for the private route areas: the owner's call. The
  design estimate for the 70 km route at 3 km is about 3.33 MB for the file and 1,401,584 B for the way-back section.
- **Grey reads and grey lines over the 17 Nov ride.** The ride track is not on the host (only the 14 Nov track).
- **Landmarks.** The cell cache predates the landmark query, so the budget run has no landmark name.
- **Own-drawer map work.** Not computed on the host. The `m<ms>` test text on the unit gives the map time.

Grey cap (owner's decision): the page charges the full work of every line in the 20 screen cells, as the unit does. With
the start cap of 60,000 px, a synthetic 60 m block grid keeps 27 % of its grey length; 100 m blocks keep 99 %, 150 m and
250 m blocks 100 %. A cap of 150,000 px keeps 100 % of all four. The cap stays at 60,000 px until the session measures
the grey time (`w<ms>`, `g<lines>`).

## Features

| Feature | Normal behaviour | Admission | Unavailable state | Restoration |
|---|---|---|---|---|
| Own line drawer (`F_OWN`) | Map, grey and way-back lines with the raster module | Page switch "Eigene Linien" (on) | Without the bit: LVGL as cc26 | Page switch off, or a cc26 file |
| Frame stops | A frame stops at 400 ms only between passes | Always | — | cc26 image |
| Test text (`F_TEXT`) | `m<ms>`; off the route `<dist>m w<ms> r<reads> g<lines>`; on the route `e<code> u<U> t<T> w<ms>` | Page switch "Testtext" (on) | Without the bit: only `<dist>m` or `wb<code>` off the route | Page switch off |
| Grey streets | Every line of the screen cells, page-proven caps | Page switch "Rückweg-Linie und graue Straßen" | No section, a bad layer, a failed anchor or a read error: no grey, the line stays | Page switch off |
| Way-back reach | 1, 2 or 3 km (default 3 km), steps down when it does not fit | Page select | Too large in every reach: no way-back data | Smaller reach on the page |
| Elevation strip (`F_ROUTE`) | Next 1 km on the route | Page switch "Höhenprofil" and a GPX with elevation | `e1` no section, `e2` progress not trusted, `e3` past the end, `e4` read failed, `e11` no heap | Page switch off |
| Names and landmarks | Names 20 m from the route and the junctions; 3 landmark types | Page layer "Straßennamen" | No name in a block | Page layer off |
| Section table | Sections found by type | Always with way-back, grey or elevation | A cc26 file (`CCWT`): `wb7` | Build the file again on the page |
